# User Authentication System

A Full Stack User Registration and Login System built using React.js, Node.js, Express.js, MongoDB, and Tailwind CSS.

## Features

- User Registration
- User Login
- Password Encryption using bcrypt
- MongoDB Database Integration
- Modern Responsive UI
- Full Stack Authentication System

## Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs
- CORS
- dotenv

## Project Structure

user-authentication-system/
│
├── frontend/
│
└── backend/

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
